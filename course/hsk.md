# Part 2: The HSK Course (HSK 1 to HSK 7–9)

## Overview

Part 2 takes you from HSK 1 to HSK 7–9: about 11,000 words and 3,000 characters, in 188 weekly units (roughly 3.5 years at 45 minutes a day). It follows the finalized HSK 3.0 syllabus, released in November 2025. Regular exams for Levels 1–6 under this syllabus start on December 13, 2026.

**You handwrite everything.** The official exam asks you to write far fewer characters than you can read. This course has you handwrite every character anyway. It is harder, but it is the only way to be able to write what you read. Part 1 already covered about 200 characters, so the early units will feel familiar; review them and focus on the words and grammar.

**How each HSK unit runs (one week)**

| Day | Work |
| --- | --- |
| 1 | First third of the word list: break each new character into its radical and sound part, write it 5 times, then 3 times from memory |
| 2 | Second third, same method; write Day 1's words from memory |
| 3 | Last third; write all the unit's words from memory |
| 4 | Grammar point: read the pattern, copy the examples, write 5 sentences of your own with it |
| 5 | Dialogue or reading: read it aloud, copy it by hand, then rewrite it from the English alone |
| 6 | Unit test, closed book and handwritten; rewrite every miss 10 times |
| 7 | Flashcard review only |

Every fifth unit is followed by a review test, and every level ends with an official mock exam. Pass each at 85% before moving on.

**About the word lists.** Each unit's words come from the core vocabulary for that level. A few words moved between levels in the final 2025 syllabus, so check your progress against the official list once per level. Pleco and most HSK flashcard decks include it.

## HSK 1 Unit 1: Greetings and identity

Goal: introduce yourself, ask someone's name and nationality, and handle thanks, apologies and goodbyes, all in handwritten characters.

**Words (20)**

| Word | Pinyin | Meaning | Character notes |
| --- | --- | --- | --- |
| 你 | nǐ | you | 亻 person + 尔 |
| 我 | wǒ | I, me | Originally a weapon; no radical hint |
| 他 | tā | he | 亻 + 也 |
| 她 | tā | she | 女 + 也: same sound, woman radical |
| 们 | men | (plural) | 亻 + 门 mén; 我们, 你们, 他们 |
| 好 | hǎo | good | 女 woman + 子 child |
| 是 | shì | to be | 日 on top |
| 不 | bù | not | Becomes bú before a 4th tone: 不是 bú shì |
| 人 | rén | person | A walking figure |
| 叫 | jiào | be called | 口 mouth |
| 名字 | míngzi | name | 名 = 夕 evening + 口: calling your name in the dark; 字 = 宀 + 子 |
| 什么 | shénme | what | 什 = 亻 + 十 |
| 谢谢 | xièxie | thank you | 讠 speech |
| 不客气 | bú kèqi | you're welcome | 客 = 宀 + 各 |
| 对不起 | duìbuqǐ | sorry | 起 = 走 walk + 己 |
| 没关系 | méi guānxi | it's OK | 没 = 氵 + 殳 |
| 再见 | zàijiàn | goodbye | 见 = see (an eye on legs) |
| 中国 | Zhōngguó | China | 国 = 囗 border + 玉 jade |
| 老师 | lǎoshī | teacher | 师 = master |
| 学生 | xuésheng | student | 学 = a child (子) under a roof, learning |

**Grammar**

1. **A 是 B.** 我是学生。 Negate with 不: 我不是老师。 是 links nouns only. Never put it before an adjective.
2. **叫 + name.** 我叫王明。 Ask: 你叫什么名字？ The question word goes where the answer goes.
3. **吗 questions.** Add 吗 to a statement to make a yes/no question: 你是中国人吗？ Never use 吗 when the sentence already has a question word like 什么.
4. **…呢？ = "And you?"** 我叫李月，你呢？

**Dialogue (read aloud, copy, then rewrite from the English)**

A: 你好！ *Hello!*

B: 你好！你叫什么名字？ *Hi! What's your name?*

A: 我叫王明。你呢？ *I'm Wang Ming. And you?*

B: 我叫李月。你是老师吗？ *I'm Li Yue. Are you a teacher?*

A: 不是，我是学生。你是中国人吗？ *No, I'm a student. Are you Chinese?*

B: 是，我是中国人。 *Yes, I'm Chinese.*

A: 谢谢！再见！ *Thanks! Bye!*

B: 不客气，再见！ *You're welcome, bye!*

**Unit test (closed book, handwritten)**

A. Write in characters: you · I · he · she · we · good · to be · not · person · be called · name · what · thank you · you're welcome · sorry · it's OK · goodbye · China · teacher · student

B. Turn into questions with 吗: 1. 他是老师。 2. 她是中国人。 3. 你们是学生。

C. Find and fix the mistake: 1. 你叫什么名字吗？ 2. 我是好。 3. 他不是中国。

D. Translate:

1. My name is (your name).
2. She is not a teacher.
3. Are they Chinese?
4. What is his name?
5. "Sorry!" "It's OK."

**Answer key**

A: 你 我 他 她 我们 好 是 不 人 叫 名字 什么 谢谢 不客气 对不起 没关系 再见 中国 老师 学生. B: 他是老师吗？ / 她是中国人吗？ / 你们是学生吗？ C: 你叫什么名字？ (no 吗 with 什么) / 我很好。 (no 是 before an adjective) / 他不是中国人。 (中国 is the country; a person needs 人) D: 我叫…。 / 她不是老师。 / 他们是中国人吗？ / 他叫什么名字？ / 对不起！—没关系。

## HSK 1 Unit 2: Numbers, age and measure words

Goal: write any number up to 9,999 in characters, ask and give ages, and count people and things with 个.

**Words (20)**

| Word | Pinyin | Meaning | Character notes |
| --- | --- | --- | --- |
| 一 | yī | one | One stroke |
| 二 | èr | two | Two strokes, the bottom one longer |
| 三 | sān | three | Middle stroke shortest |
| 四 | sì | four | 囗 frame, closed last |
| 五 | wǔ | five |  |
| 六 | liù | six |  |
| 七 | qī | seven | Horizontal, then the hooked stroke |
| 八 | bā | eight | Two strokes parting |
| 九 | jiǔ | nine |  |
| 十 | shí | ten | A cross: horizontal first |
| 零 | líng | zero | 雨 rain on top + 令 lìng (sound) |
| 百 | bǎi | hundred | 一 + 白 bái |
| 千 | qiān | thousand |  |
| 两 | liǎng | two (before measure words) |  |
| 几 | jǐ | how many (small numbers) |  |
| 多少 | duōshao | how many, how much | 多 = two 夕 stacked |
| 个 | gè | (general measure word) | 人 + 丨 |
| 岁 | suì | years old | 山 + 夕 |
| 大 | dà | big; old (age) | A person with arms spread |
| 了 | le | (change / completion) | Two strokes |

**Grammar**

1. **Building numbers.** 11 = 十一, 20 = 二十, 99 = 九十九, 105 = 一百零五 (零 marks the gap), 250 = 二百五十, 3,000 = 三千.
2. **两 vs 二.** Use 两 before a measure word (两个人) and 二 when counting or in numbers (十二, 第二). 200 and 2,000 can be 两百 / 两千.
3. **Number + measure word + noun.** 三个学生, never 三学生. 个 is the default measure word; you'll learn specific ones (本, 杯, 件) as you go.
4. **几 vs 多少.** 几 expects an answer under about ten and needs a measure word (几个人？). 多少 is for any number, and the measure word is optional (多少人？).
5. **Age.** 我二十五岁。 Don't add 是. Ask a child 你几岁了？, an adult 你多大了？

**Dialogue**

A: 你多大了？ *How old are you?*

B: 我二十八岁。你呢？ *I'm 28. And you?*

A: 我三十一岁。你们有几个老师？ *I'm 31. How many teachers do you have?*

B: 两个老师，九十个学生。 *Two teachers and ninety students.*

**Unit test (closed book, handwritten)**

A. Write in characters: 15 · 23 · 99 · 100 · 108 · 360 · 1,000 · 2,500 · 4,060

B. Write the 20 words from the English: one through ten, zero, hundred, thousand, two (before measure words), how many (small), how many (any), measure word, years old, big, (change particle).

C. Fill in 两 or 二: 1. （ ）个人 2. 十（ ） 3. （ ）十岁 4. （ ）个学生

D. Translate:

1. How old are you? (to an adult)
2. I'm thirty.
3. three teachers
4. How many students? (any number)
5. How old is your younger brother? He is six.

**Answer key**

A: 十五 · 二十三 · 九十九 · 一百 · 一百零八 · 三百六十 · 一千 · 两千五百 · 四千零六十. B: 一 二 三 四 五 六 七 八 九 十 零 百 千 两 几 多少 个 岁 大 了. C: 两, 二, 二, 两. D: 你多大了？ / 我三十岁。 / 三个老师 / 多少学生？ / 你弟弟几岁了？他六岁。

## HSK 1 Unit 3: Family and possession

Goal: describe your family, say what you have and don't have, and use 的, 也, 都 and 很 correctly.

**Words (20)**

| Word | Pinyin | Meaning | Character notes |
| --- | --- | --- | --- |
| 家 | jiā | home, family | 宀 + 豕 (Part 1, Unit 12) |
| 爸爸 | bàba | dad | 父 father + 巴 bā (sound) |
| 妈妈 | māma | mom | 女 + 马 mǎ |
| 哥哥 | gēge | older brother | Two 可 stacked |
| 姐姐 | jiějie | older sister | 女 + 且 |
| 弟弟 | dìdi | younger brother |  |
| 妹妹 | mèimei | younger sister | 女 + 未 |
| 儿子 | érzi | son | 儿 = child |
| 女儿 | nǚ'ér | daughter | woman + child |
| 孩子 | háizi | child | 孩 = 子 + 亥 hài |
| 朋友 | péngyou | friend | 朋 = two 月 side by side |
| 有 | yǒu | have; there is | A hand holding meat (月 = flesh) |
| 没有 | méiyǒu | not have | Always 没, never 不, with 有 |
| 的 | de | (possessive) | 白 + 勺 |
| 和 | hé | and | 禾 grain + 口 |
| 也 | yě | also |  |
| 都 | dōu | all, both | 者 + 阝 (city) |
| 很 | hěn | very | 彳 step + 艮 |
| 爱 | ài | love | The traditional 愛 has 心 heart in the middle; simplified dropped it |
| 口 | kǒu | (measure word for family members) | mouth: one mouth to feed |

**Grammar**

1. **有 / 没有.** 我有两个姐姐。 我没有哥哥。 Never 不有.
2. **的 for possession.** 老师的名字 (the teacher's name). Drop 的 for close people and groups: 我妈妈, 我家, 我们学校.
3. **也 and 都 go right before the verb.** 我也是学生。 他们都是老师。 Both together: 他们也都是学生。 (也 before 都)
4. **很 + adjective.** 我妈妈很好。 An adjective is the verb itself, so there is no 是, and a plain statement needs 很.
5. **和 joins nouns only.** 爸爸和妈妈. Never use it to join two sentences.

**Dialogue**

A: 你家有几口人？ *How many people are in your family?*

B: 我家有四口人：爸爸、妈妈、哥哥和我。你有哥哥吗？ *Four: Dad, Mom, my older brother and me. Do you have an older brother?*

A: 我没有哥哥，我有两个妹妹。 *I don't have an older brother; I have two younger sisters.*

B: 你妹妹也是学生吗？ *Are your sisters students too?*

A: 是，她们都是学生。 *Yes, they're both students.*

**Unit test (closed book, handwritten)**

A. Write in characters: home · dad · mom · older brother · older sister · younger brother · younger sister · son · daughter · child · friend · have · not have · (possessive) · and · also · all · very · love · (family measure word)

B. Find and fix the mistake: 1. 我不有弟弟。 2. 他是很好。 3. 也我是学生。 4. 他们是都老师。

C. Translate:

1. I don't have a younger brother.
2. My dad and mom are both teachers.
3. My friend's son is five.
4. She also has a daughter.
5. I love my family.

**Answer key**

A: 家 爸爸 妈妈 哥哥 姐姐 弟弟 妹妹 儿子 女儿 孩子 朋友 有 没有 的 和 也 都 很 爱 口. B: 我没有弟弟。 / 他很好。 / 我也是学生。 / 他们都是老师。 C: 我没有弟弟。 / 我爸爸和妈妈都是老师。 / 我朋友的儿子五岁。 / 她也有一个女儿。 / 我爱我家。

## HSK 1 Unit 4: Time and dates

| --- | --- | --- | --- |
| 今天 | jīntiān | today | 天 = a person (大) under the sky line |
| 明天 | míngtiān | tomorrow | 明 = sun + moon (Part 1, Unit 8) |
| 昨天 | zuótiān | yesterday | 昨 = 日 + 乍 |
| 年 | nián | year |  |
| 月 | yuè | month; moon |  |
| 日 | rì | day (written dates) |  |
| 号 | hào | day of the month (spoken); number | 口 on top |
| 星期 | xīngqī | week | 期 = 其 + 月 moon |
| 天 | tiān | day; sky |  |
| 点 | diǎn | o'clock; dot | 灬 fire dots at the bottom |
| 分 | fēn | minute | 八 split + 刀 knife: to divide |
| 半 | bàn | half |  |
| 现在 | xiànzài | now | 现 = 王 jade + 见 |
| 时候 | shíhou | time, when | 候 = 亻 + wait |
| 上午 | shàngwǔ | morning (until noon) | 午 = noon |
| 中午 | zhōngwǔ | noon |  |
| 下午 | xiàwǔ | afternoon |  |
| 早上 | zǎoshang | early morning |  |
| 晚上 | wǎnshang | evening |  |
| 生日 | shēngrì | birthday |  |

**Grammar**

1. **Dates go from big to small.** 2026年11月25日 is written; 十一月二十五号 is spoken. Years are read digit by digit: 二零二六年.
2. **Days of the week.** 星期 + number: 星期一 (Monday) to 星期六 (Saturday). Sunday is 星期天 or 星期日. Ask 今天星期几？
3. **Clock time.** 八点 (8:00), 八点十五分 (8:15), 八点半 (8:30). Put the part of the day first: 下午三点 (3 p.m.).
4. **Time words come before the verb, never after.** 我明天去。 or 明天我去。 Never 我去明天。
5. **是 is optional with dates and times.** 今天星期三。 现在两点。 To negate, 是 comes back: 今天不是星期三。

**Dialogue**

A: 今天几月几号？ *What's the date today?*

B: 今天十一月二十五号，星期三。 *Today is November 25th, Wednesday.*

A: 明天是我的生日！ *Tomorrow is my birthday!*

B: 是吗？你的生日是十一月二十六号？ *Really? Your birthday is November 26th?*

A: 对。现在几点？ *Yes. What time is it now?*

B: 现在下午两点半。 *It's 2:30 in the afternoon.*

## HSK 1 Unit 5: Places and location

Goal: say where people and things are, ask where something is, and talk about going and coming.

**Grammar**

1. **在 as a verb: "be at."** 老师在学校。 Ask: 医院在哪儿？ Negate with 不: 他不在家。
2. **在 as "at" before a verb.** 我在学校学习。 The place comes before the action, unlike English.
3. **Noun + 里 / 上 / 下.** Most objects need a location word: 在桌子上 (on the table), 在学校里 (in the school). Countries and cities don't: 在北京.
4. **去 / 来 + place, with nothing in between.** 我去北京。 你来我家吧。 Never 去到北京 or 去在北京.
5. **这 / 那 / 哪 + measure word + noun.** 这个商店, 那个人, 哪个学校？

**Dialogue**

A: 你去哪儿？ *Where are you going?*

B: 我去医院。你呢？ *I'm going to the hospital. And you?*

A: 我去火车站。医院在哪儿？ *I'm going to the train station. Where is the hospital?*

B: 医院在学校后面。 *The hospital is behind the school.*

A: 那个商店也在那儿吗？ *Is that shop there too?*

B: 不在，商店在饭店前面。 *No, the shop is in front of the restaurant.*
