### Grammar

1. **Verb + result:** 完 (finished), 好 (done properly, ready), 懂 (understood), 见 (perceived), 到 (reached, achieved), 错 (wrongly), 会 (mastered), 住 (fixed firmly), 干净 (clean).
2. **了 goes after the result:** 我做完了。我看见他了。
3. **Negate with 没, drop 了:** 我没听懂。他没做完。
4. **Questions:** 你听懂了吗？ / 你听懂没有？
5. **看 vs 看见:** 看 is the action (look); 看见 is the result (actually see). Same for 听 / 听见.

### Dialogue

A: 你复习完了吗？明天考试。 *Have you finished reviewing? The exam's tomorrow.*

B: 还没复习完。这道题我没看懂。 *Not yet. I didn't understand this question.*

A: 我看看……你写错了一个字，答案应该是这个。 *Let me see… you wrote a character wrong; the answer should be this.*

B: 哦，我看见了。谢谢！ *Oh, I see it now. Thanks!*

A: 上次老师对你的成绩满意吗？ *Was the teacher happy with your grade last time?*

B: 很满意。我们一起检查一下吧。 *Very. Let's check it together.*

### Grammar

1. **Verb + 来 / 去:** 来 means toward the speaker, 去 away. Upstairs calling down: 你上来吧！ Answering from downstairs: 我马上上去。
2. **Compound direction:** verb + 上 / 下 / 进 / 出 / 回 / 过 / 起 + 来 / 去: 走进来，跑出去，拿回来，站起来。
3. **A place goes between the verb and 来 / 去:** 进教室来，回家去，上楼来。 Never 回去家.
4. **A thing can go before or after 来 / 去:** 拿一本书来 = 拿来一本书。
5. **起来 = up from lying or sitting:** 站起来。 **掉下来 / 掉下去 = fall down** (toward or away from you).

### Dialogue

A: 你在楼上吗？快下来吧！ *Are you upstairs? Come down!*

B: 我马上下去。你上来帮我拿箱子，好吗？ *I'm coming down. Could you come up and help me with a box?*

A: 你们楼有电梯吗？ *Does your building have an elevator?*

B: 没有，你走楼梯上来吧。 *No, take the stairs up.*

A: 好。……这个箱子太重了，先放下吧。 *OK. …This box is too heavy; put it down for now.*

B: 我们一起搬下去吧。 *Let's carry it down together.*

### Grammar

1. **Verb + 得 + result = can; verb + 不 + result = can't:** 听得懂 / 听不懂，看得见 / 看不见，吃得完 / 吃不完，找得到 / 找不到。
2. **Works with directions too:** 上得去 / 上不去，回得来 / 回不来。
3. **来得及 / 来不及 = there's time / there isn't.**
4. **Verb + 不了 = can't (at all, or can't manage that amount):** 吃不了，去不了。
5. **Questions:** 你听得懂吗？ or 你听得懂听不懂？
6. **Prefer these over 能:** say 我听不懂, not 我不能听懂.

### Grammar

1. **Subject + 把 + object + verb + something more:** 我把作业做完了。 The object is a specific, known thing.
2. **The verb can't stand alone.** It needs a result, a direction, a place or 了: 把书放在桌子上。把门关上。 Never 我把书看.
3. **Common endings:** 把…放在 (put at), 把…送到 (deliver to), 把…借给 (lend to), 把…翻译成 / 换成 (turn into).
4. **Negatives and modals go before 把:** 我没把作业带来。别把手机忘了。
5. **Why use it:** 把 focuses on what happened to the thing. It's how Chinese gives instructions about objects.

### Grammar

1. **Receiver + 被 + (doer) + verb + something more:** 我的自行车被偷了。我被老师批评了。
2. **The doer can be left out:** 被（人）偷了。
3. **The verb needs an ending, just like 把:** 了, a result or a direction. Never 我的车被偷.
4. **Negatives go before 被:** 我没被批评。
5. **In speech 被 usually marks something bad or unexpected,** but good news works too: 她被老师表扬了。
6. **Spoken alternatives:** 叫 or 让 can replace 被 when the doer is named: 钱包让小偷偷了。

### Grammar

### Grammar

1. **不但…，而且…** = not only … but also. With one subject, put it before 不但: 他不但会说汉语，而且会写书法。
2. **除了…（以外），还 / 也…** = besides (adding): 除了书法以外，我还学吉他。

### Grammar

6. **按时 = on schedule; 准时 = punctual; 及时 = in time:** 请按时吃药。他总是很准时。医生来得很及时。

### Grammar

1. **Number + measure word + 左右 = about (左右 goes after):** 他三十岁左右。五点左右见。
2. **大约 / 大概 + number = approximately (goes before):** 大约来了五十个人。

5. **至少 = at least; 最多 = at most:** 至少要三天。最多二十个人。
6. **百分之 + number = percent; 增加了一倍 = doubled:** 百分之三十的人同意。价格增加了一倍。

### Grammar

1. **Verb + 过 = have done it before (an experience); negative 没 + verb + 过:** 我去过长城。我还没去过博物馆。
2. **一边 A 一边 B = do A while doing B:** 他一边走路一边听音乐。

### Grammar

1. **正在 / 正 + verb + 的时候 = just as, while (sets the scene):** 我正在洗澡的时候，电话响了。
2. **突然 / 忽然 = suddenly; verb + 起 + object + 来 = start doing:** 天突然下起雨来了。
3. **于是 = so, and then (an action that follows from the last one):** 他没带伞，于是在商店里等雨停。
4. **后来 = later on, for the past only; 以后 works for past and future:** 后来我们成了好朋友。以后我会去北京。
5. **原来 = so it turns out (a discovery):** 原来是你啊！
6. **结果 = and as a result, in the end (often something you didn't want):** 路上车太多，结果我们都迟到了。

### Dialogue

A: 你昨天怎么没来上课？发生什么事了？ *Why weren't you in class yesterday? What happened?*

B: 我正在等车的时候，一个小偷突然拿走了我的包。 *While I was waiting for the bus, a thief suddenly grabbed my bag.*

A: 啊？你当时害怕吗？ *What? Were you scared?*

B: 只是很吃惊，于是我马上给警察打了电话。 *Just shocked, so I called the police straight away.*

A: 后来呢？ *And then?*

B: 警察很快就找到了他。原来他就住在我家旁边！ *The police found him fast. Turns out he lives right next door!*
